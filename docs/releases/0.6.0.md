# Codex Assist 0.6.0

Codex Assist 0.6.0 lets one Codex sign-in serve several Assist conversation agents. Each agent has its own name, prompt, model, and search setting. Existing installs upgrade in place and keep their entity IDs, settings, and sign-in.

## Changes

- Serve several Assist conversation agents from one sign-in. Select **Add conversation agent** on the Codex Assist integration page to add one. Each agent is its own conversation entity that you can choose in any Assist pipeline, with its own system prompt, chat model, reasoning effort, response length, and hosted web search setting. ([#85](https://github.com/itsreverence/ha-codex-assist/pull/85))
- Give the AI Task entity its own settings: chat model, reasoning effort, response length, hosted web search, and image defaults. The AI Task no longer uses the conversation agent's system prompt. It uses fixed AI Task instructions. ([#85](https://github.com/itsreverence/ha-codex-assist/pull/85))
- Replace the integration options form with per-agent settings. To change an agent or the AI Task, select the gear icon next to it on the integration page. ([#85](https://github.com/itsreverence/ha-codex-assist/pull/85))
- Give each agent and the AI Task its own Codex prompt-cache session. Before, all requests from one sign-in shared a session. The first request from each agent after the upgrade is not cached. ([#85](https://github.com/itsreverence/ha-codex-assist/pull/85))
- Suggest the current gpt-6 models when account model discovery fails. ([#82](https://github.com/itsreverence/ha-codex-assist/pull/82))
- Update CI dependencies. ([#83](https://github.com/itsreverence/ha-codex-assist/pull/83), [#84](https://github.com/itsreverence/ha-codex-assist/pull/84))

Thanks to [DaFern](https://github.com/DaFern), whose fork's multiple-assistant profiles gave us the idea for #85.

## Updating

**Take a full Home Assistant backup before you update.** On first start, 0.6.0 moves your settings into the new per-agent layout. Codex Assist 0.5.0 and earlier cannot load the upgraded entry. To roll back, restore the backup. If Codex rotated your sign-in after the backup, you need to sign in again.

Update through HACS and restart Home Assistant. Your existing agent becomes the first conversation agent and keeps its entity ID, so Assist pipelines that use it keep working. Your AI Task entity keeps its entity ID and settings. You do not need to sign in again.

If you set a custom system prompt, it now applies only to the conversation agent. AI Tasks that relied on that prompt use the fixed AI Task instructions instead.

Callers that address the agent by its config entry ID instead of its entity ID reach the first conversation agent.

Fallback model suggestions remain unchanged after reviewing the [official model guidance](https://learn.chatgpt.com/docs/models) on November 10, 2026. Account discovery remains authoritative, and saved model selections are never replaced automatically.

Home Assistant 2026.6.0 remains the minimum. The downstream Codex service interface remains an undocumented, unstable dependency. Hosted search remains opt-in.

# Codex Assist 0.4.8

When web search is enabled, Assist conversations and unstructured AI Tasks now use Codex's standalone search endpoint instead of the built-in search tool. This change addresses reported failures with the built-in tool.

- Keeps intermediate search text out of answers and preserves search results across Home Assistant tool calls and follow-up questions.
- Limits search calls and reports malformed search responses as failures rather than empty results.
- Updates tool-result handling for Home Assistant 2026.10 while retaining support for older versions.

Web search remains opt-in and uses an undocumented endpoint.

Update through HACS and restart Home Assistant. You can keep your existing sign-in and settings.

Thanks to @davbebawy for contributing the client-side search implementation in [PR #52](https://github.com/itsreverence/ha-codex-assist/pull/52).
